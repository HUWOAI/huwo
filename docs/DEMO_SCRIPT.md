## 评委问答要点

**Q：为什么不是 Chatbot？**  
A：有工具调用与轨迹；输入到规划/提醒可验证交付。

**Q：为何不开源全部 APP？**  
A：内核开源保证可复现；社交与用户数据是商业壁垒。

**Q：和美团/豆包区别？**  
A：垂直饮食 + 家庭约束记忆 + 机器人交付；不做通用闲聊。
