## 评委问答要点

**Q：为什么不是 Chatbot？**  
A：有工具调用与 trajectory；输入到规划/提醒/匹配可验证交付。

**Q：为何不开源全部 APP？**  
A：内核开源保证可复现；账号与用户数据是商业与合规边界。

**Q：和通用助手区别？**  
A：家庭约束记忆 + 三引擎闭环 + 持证经营叙事；不做泛闲聊。
