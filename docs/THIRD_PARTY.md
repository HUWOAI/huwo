# 第三方与商业 API 披露（开源仓）

| 服务 | 本仓库中的角色 | 是否必需 |
|------|----------------|----------|
| 火山方舟 | `providers/` 可选聊天 | 否（规则 Demo 不需要） |
| MiniMax | 可选 Provider 示例 | 否 |
| 京东秒送等 | `integrations/` 深链**示意** | 否 |
| FastAPI 等 | `requirements.txt` | 是（跑 Demo） |

密钥仅通过 `.env` 本地配置，**禁止提交**真实 Key。  
生产环境还使用语音 ASR/TTS、RTC、云数据库等，详见团队参赛「商业 API 披露」文档；不在本开源仓内放置生产配置。
