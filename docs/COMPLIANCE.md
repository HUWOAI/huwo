# 合规要点摘要（开源仓）

> 完整说明见商业仓 `doc/AIGO/05_数据合规说明_提交版.md` 与平台总纲。本文件便于评委在开源仓库内快速核对。

## 产品边界

| 能力 | 允许 | 禁止 |
|------|------|------|
| 饮食建议 | 偏好/过敏约束下的菜单与百科 | 医疗诊断、处方 |
| 吃药提醒 | 日程提醒（任务助手） | AI 审方、改药、诊疗结论 |
| 家政评测 | 规则透明评分、挂牌匹配示意 | 伪造背调结论、歧视性排序 |
| 保险 | 「建议投保（占位）」引导 | 承保/赔付确定性结论 |
| AI 内容 | 标识为 AI 生成（商业版气泡已标） | 伪称真人医师/药师 |

## 数据

- 开源 Demo 默认使用样本 JSON，无真实用户数据。
- API Key / 开放平台密钥不入库，仅 `.env.example` 占位。
- 商业版表前缀 `AIEAT_`，账号与家庭记忆闭源。

## 第三方披露

火山方舟、语音/RTC、MiniMax、京东秒送（商业版对接）等须在材料中披露；开源仓对应模块为调用封装或深链示意。
