## 产品边界

| 能力 | 允许 | 禁止 |
|------|------|------|
| 饮食建议 | 偏好/过敏约束下的菜单与百科 | 医疗诊断、处方 |
| 吃药提醒 | 日程提醒（任务助手） | AI 审方、改药、诊疗结论 |
| 家政评测 / 匹配 | 规则透明评分、≥3 条解释、挂牌匹配示意 | 伪造背调、歧视性排序、替代录用、保证就业 |
| 眼镜 / 在岗影像 | 授权下的事件制记录；离岗 ACL 关闭雇主访问 | 未授权录音录像、宣称为 24h 监控 |
| 保险 | 投保引导占位（商业版） | 承保/赔付确定性结论 |

## 数据

- 开源 Demo 默认使用样本 JSON，无真实用户数据。  
- API Key 不入库，仅 `.env.example` 占位。
